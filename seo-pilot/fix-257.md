# SEO fix: SITEMAP_MISSING

**Page:** http://localhost:8099/sitemap.xml

**Problem:** No XML sitemap found.

**Why:** The site is missing an XML sitemap, which search engines use to discover and index content efficiently. Without it, crawlers may miss pages, leading to lower crawl budget usage and slower indexation, hurting rankings. Adding a properly formatted sitemap and submitting it to search console will improve crawl efficiency and visibility.

**Proposed value:** 

```html
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
</urlset>
```
